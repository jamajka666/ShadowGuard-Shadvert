# ShadowGuard Shadvert — Šablona TV / velký displej

**Breakpoint:** ≥ 1920px (TV, velký monitor ze sedačky)  
**Princip:** jako MONITOR, ale **větší typografie, větší CTA, méně hustoty**  
**Master:** `00-MASTER-layout-foundation.md`

---

## Above-the-fold

Stejná skládanka:

1. Header (název + Stručný/Detailní + Hlas + Nastavení + Připojeno)  
2. Okno inzerátu  
3. Zlaté Prověřit  

Obsah centrovaný v komfortní šířce (~1000–1200px), okolí klidné (bez rušivých drobných prvků).

---

## Rozměry (orientační)

| Role | Min. |
|------|------|
| Body | 22px |
| Label | 24px |
| Název | 28–32px |
| CTA výška | ≥ 64px |
| Touch/focus target | ≥ 56px |

Focus stavy výrazné (TV ovládání / dálkový + klávesnice).

---

## Layout

- Spíš **jednoduchý středový sloupec** než hustý side-by-side  
- Pokud side-by-side, jen quick akce; CTA vždy plně viditelné  
- Žádné prvky pod foldem viditelné „náhodou“ kvůli obří výšce — fold = first screen / 100vh  

---
